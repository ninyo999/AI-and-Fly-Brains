# Project Description
Opioid painkillers are widely use and highly effective but it also has a serious side effect on brain structure, neural circuits and cause an addiction. To replace opioids usage, is to discover alternative non-addictive painkillers to reduce the impacts of opioid abuse. Traditionally, to study pain, researcher use an animal such as rats, dogs, or monkey to test a new drug. However, ethical considerations and constraints limit their experimental use. An alternative approach is to use Drosophila melanogaster (D.M) larvae for a beginning test before using mammalian models since they reproduce rapidly, genetically tractable, and are ethically much less compromising. Nevertheless, for a painkillers test, researcher study about pain of DM from it’s nocifensive reaction: when they feel pain, they will perform corkscrew-like rolling motion to escape. But using traditional mechanical stimulation methods to stimulate such as using needles to touch individual larve are unsuitable for large-scale testing which requires precision and validity.
To solve this limitation, this project aims to develop an AI-driven experimental tools for studying pain and aversive in fruit flies larval for a painkillers test which using optogenetics stimulation: to stimulate nocifensive behaviours of D.M, with AI to detect larval and identify their reaction; The system work as block diagram in Figure 1 and AI implementation is work as block diagram in Figure 2. And as a continuation of two previous research from C. Ashdown and S. Cac: Final Year Individual Project Thesis AI and fly brains – tools to study pain and aversive learning in fruit flies, this project will focus on improving the existing system by changing the camera system to Teledyne DALSAGenie Camera system and new AI and software implementation to analyse data.
